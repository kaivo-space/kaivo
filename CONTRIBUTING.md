# Contributing to Kaivo

Thank you for your interest in contributing to Kaivo.

## Current Status

The platform architecture is frozen.

At this stage, only repository infrastructure, documentation, and development environment improvements are accepted.

Application code is not yet part of this repository.

## Contribution Process

1. Create a dedicated branch.
2. Keep commits focused and descriptive.
3. Open a Pull Request.
4. Wait for review before merging.

Thank you for helping improve Kaivo.
